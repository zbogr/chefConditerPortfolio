# Chef Portfolio (vanilla)

Сайт-візитка шеф-кондитера на чистому **HTML + CSS + JavaScript**.
Без фреймворків, без збірки, без залежностей.

## Призначення

Сайт має суто **інформативний характер** і продає бренд, обличчя та
професіоналізм майстра. Тут **немає цін і рецептів** — лише портфоліо робіт,
досягнення та контакти. Описи категорій і робіт описують стиль, настрій і
підхід, а не склад чи технологію.

## Іміджеві секції головної

- Hero, цитата, «Про мене» з переліком переваг.
- **У цифрах** — досвід і професіоналізм (статистика).
- **Моя філософія** — три цінності з іконками.
- **Знайомство** — портрет майстра + коротка біографія.

> ⚠️ Увесь текст, цифри та біографія — **випадкові заглушки**. Перед публікацією
> замініть їх на реальні матеріали. Портрет у секції «Знайомство» — це
> emoji-заглушка: вставте `<img>` усередину `.portrait-figure` (або задайте
> фон у `css/pages.css`).

## Запуск

Просто відкрийте `index.html` у браузері. Або підніміть локальний сервер
(рекомендовано, щоб коректно працювали відносні шляхи):

```
npx serve .
# або
python -m http.server 5500
```

## Як це працює

- **Багатосторінковість:** окремі HTML-файли, спільні хедер/футер
  рендеряться з `js/layout.js` у `<header id="site-header">` та
  `<footer id="site-footer">`.
- **Локалізація:** тексти мають атрибут `data-i18n="ключ"` (або
  `data-i18n-attr="placeholder:ключ"`). `js/i18n.js` підставляє переклад і
  зберігає вибір мови в `localStorage`. Перемикач — кнопки `data-lang="uk|en"`.
- **Дані:** усе в `js/data.js`. Щоб додати страву — додайте об'єкт у `dishes`
  із потрібним `categoryId`.
- **Мобільний бургер:** клас `menu-open` на `<body>` показує мобільне меню.
  На екранах від 768px показується звичайна навігація.

## Додавання зображень

1. Покладіть файли у `assets/images/{hero,dishes,certificates}`.
2. У `js/data.js` вкажіть шлях у полі `image`, наприклад
   `image: "assets/images/dishes/berry-cake.jpg"`.
3. Якщо `image` порожній (`null`) — показується emoji-заглушка.

## Форма пошти

За замовчуванням форма формує `mailto:`-посилання (відкриває поштовий клієнт).
Щоб надсилати без поштового клієнта, підключіть безбекендний сервіс:

- **FormSubmit:** змініть `action` форми на `https://formsubmit.co/ваш@email`
  і приберіть `preventDefault` у `js/pages.js`.
- **EmailJS:** додайте SDK і викличте `emailjs.send(...)` у обробнику
  сабміту замість формування `mailto:`.

## Особливості

- Єдиний світлий стиль (без темної теми).
- Mobile-first: базова верстка під телефон, десктоп — через
  `@media (min-width: 560px/768px/900px)`.
- Нижньої навігації немає — на мобільному лише бургер угорі.
- Жодних зовнішніх запитів: шрифти системні, іконки локальні.
